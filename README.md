# ejecutar en desarrollo 

1. Clonar el repositorio
2. ejecutar

```
npm install 
```

3. Tener Nest CLI instalado
```
npm i -g @nestjs/cli
```

4. Levantar la base de datos
```
docker-compose -up -d
```

4. recosntruir la base de datos
```
http://localhost:3000/api/v2/seed
```

## Stack Usado
* Mongo
* Nest
